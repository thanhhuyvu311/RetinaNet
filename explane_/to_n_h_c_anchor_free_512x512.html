2. Điểm Lưới Đang Chọn (Center Point)

Tọa độ điểm: (..., ...)

3. Lúc Huấn Luyện (Training)

Tính khoảng cách từ Điểm Tâm đến 4 cạnh của vật thể để làm mục tiêu học (Target):

l = c_x - x_min = ... = ...
t = c_y - y_min = ... = ...
r = x_max - c_x = ... = ...
b = y_max - c_y = ... = ...

Mạng NN sẽ được train để xuất ra Tensor [l, t, r, b] này.

4. Lúc Dự Đoán (Inference)

Khi có ảnh mới, từ tọa độ lưới đã biết và [l, t, r, b] mạng dự đoán ra, ta vẽ ngược lại Box:

x_min = c_x - l = ... = 111.0
y_min = c_y - t = ... = 28.0
x_max = c_x + r = ... = 143.0
y_max = c_y + b = ... = 72.0
